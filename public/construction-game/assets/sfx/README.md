# SFX drop-in folder

Drop CC0 `.ogg` construction sounds here (`hammer.ogg`, `ambience.ogg`, `floor.ogg`, `building.ogg`,
`alarm.ogg`), then uncomment the matching lines in `src/audio/AudioManager.js` `SFX_MANIFEST`.
Until then the game uses the procedural synth. See `docs/superpowers/assets-acquisition.md`.
