## 2. 시스템 · 스코어링

### 2.1 무대 · 조작 (WASD 주방 평면)
고정 ¾ "백카운터 뷰" — 주인장 뒤에서 주방 평면을 비스듬히 내려보며 플랫폼까지 조망.
```
        [심야 플랫폼 / 증기기관차 실루엣 배경]
   🧍군인  🧍할머니  🧍통학생  🧍연인  🧍회사원   손님 슬롯 4~5
  ═══════════ 카운터 + 픽업대 ═══════════
  ┌──────── 주방 평면 · WASD로 누빔 ────────┐
  │  ①사리세팅대      ②데치기 채반            │
  │                          ③육수솥          │
  │      🧑‍🍳            ④고명·고춧가루대  →픽업 │
  └──────────────────────────────────────────┘
```
- **데스크톱**: `WASD` 평면 이동 · 스테이션/손님 근접 시 `E`(또는 `Space`/클릭) 상호작용. 스테이션 클릭 시 자동 이동+상호작용.
- **모바일**: 좌하단 **가상 조이스틱**(ppopgi 아날로그 패턴 재활용) + 우하단 **액션 버튼**. 보조 tap-to-move.
- **운반**: 한 번에 그릇 1개. **동선 최적화 자체가 핵심 전략**(스테이션 분산 배치).

### 2.2 조리 — 4단계 파이프라인
| 단계 | 액션 | 비중 |
|---|---|---|
| **① 사리 세팅** | 빈 그릇 집어 **미리 삶은 면사리** 올리기 (고증: "미리 삶아둔 가락면") | 가벼움 — 동선 시작점 |
| **② 데치기/토렴** ★ | 뜨거운 육수에 데움. **덜익음 / 적정(완성도 만점) / 불음** 타이밍 게이지. 동시 2~3구 저글링. 시대↑ 적정 윈도 좁아짐 | **핵심 손맛** |
| **③ 육수 붓기** | 멸치육수 **홀드로 붓고 적정선에서 떼기**(과하면 넘쳐 감점) | 중간 |
| **④ 고명·고춧가루 마감** | 주문대로 고명 + **셀프 고춧가루(기본/많이/안 맵게)**. 정확도 채점 | 중간 — 변형축 |

→ 픽업대 → 손님 배식. 여러 주문이 이 체인 위에서 동시 진행. **깊이 = 병렬 멀티주문 × 동선 × 데치기 저글링 × 정차 타이머.**

### 2.3 손님 — 5아키타입 (서사 축 = 정서의 기둥)
| 손님 | 인내심(게이지 만탄·제안값) | 주문 성향 | 캐릭터 |
|---|---|---|---|
| **군인**(휴가·복귀) | ~12s ⚡ | 곱빼기 | 우렁참, 가끔 단체 러시 |
| **회사원** | ~15s | 고춧가루 많이 | 피곤한 야근러 |
| **통학생** | ~18s | 기본 | 풋풋한 단골 |
| **연인** | ~24s | **2그릇 동시**(같이 나와야 만족) | 도란도란 |
| **귀성 할머니** | ~25s | 안 맵게 / 뜨겁지 않게 | 충청·전라 사투리, 정(情) |

각 손님: 머리 위 **초조 게이지** + 주문 말풍선(음성+아이콘). 정확·정시 배식 = 만족+콤보 / 지연·오배식 = 이탈+감점. **변형: 연인 페어, 군인 단체 러시.**

### 2.4 이중 압박 레이어 (긴장 엔진)
| 시계 | 정체 | 효과 |
|---|---|---|
| **정차 타이머**(전체) | 화면 상단 큰 카운트다운 = 열차 출발까지 | 0 → 출발 → 남은 손님 **전원 이탈** |
| **초조 게이지**(개인) | 손님 머리 위, 주문 시점부터 차오름 | 급한 손님은 정차 끝 **전에** 떠남 → 우선순위 압박 |

게이지: 초록(여유) → 노랑(조급) → 빨강(이탈 직전, 깜빡+재촉).

### 2.5 웨이브 = 열차 1대 · 시대 곡선 (제안값, 플레이테스트 튜닝)
| 웨이브 | 시대 | 정차시간 | 손님수 | 주문 | 데치기 윈도 |
|---|---|---|---|---|---|
| W1 | 증기 | 75s | 3 | 기본 | 넓음 |
| W2 | 증기 | 70s | 4 | +변형 1종 | 넓음 |
| W3 | 디젤 | 55s | 5 | 변형 다수 +연인 페어 | 중간 |
| W4 | 디젤 | 50s | 6 | +군인 단체 러시 | 중간 |
| **W5** | **막차** | **40s** | **7~8** | 풀 변형 | 좁음 |

- 손님은 슬롯(4~5)이 비면 **시차 스폰**. 웨이브 사이 짧은 인터미션(안내방송+정산).
- **W5 = "대전발 0시 50분 목포행 막차" 클라이맥스** (고증 실재). 가장 어두운 플랫폼·긴장 최고조.

### 2.6 진행 · 실패
**5웨이브 완주형 + 이탈 라이프**: 손님 이탈 누적 한도(**5명**) 초과 시 *영업 종료*. 완주 시 총점 집계, **최고기록 localStorage**.

### 2.7 스코어 · 콤보 · 페널티
```
배식 점수 = (기본 100 + 완성도 + 속도 + 정확) × 콤보배수
```
| 항목 | 값(제안) |
|---|---|
| 기본 | +100 |
| 완성도(데치기) | 퍼펙트 +50 / 굿 +20 / 덜익음·불음 0 |
| 속도 | 초조 게이지 잔여비율 × 50 |
| 정확 | 주문 완전일치 +30 |
| 콤보배수 | 1.0 → **최대 3.0** (streak 2부터, step ~0.4, ×3 at streak 6) |

- **콤보**: 연속 만족 배식마다 ↑. **오배식·이탈·지연 → 즉시 리셋.** 빈 배식·오배식은 콤보 안 줌(farming 방지).
- **특수 보너스**: 연인 페어 / 군인 러시 완수 / 막차 W5 클리어.
- **페널티**: 손님 이탈 −80 + **라이프 −1** · 오배식 기본점 절반·보너스 0·콤보 리셋 · 불은면/넘친육수 완성도 0.
- **결과 등급/칭호**: "역전의 명인" · "면치기 9단" · "고춧가루 테러리스트" · "기차 도살자" · "0시 50분의 사나이" 등.

### 3.2 아트 파이프라인 (절차적 + 교체 가능 구조)
- **기본 = 절차적 지오메트리** (빌드리스 Three.js, 테마 정밀, 결 통일). *보유 에셋팩(KayKit 판타지·Quaternius 현대도시)은 테마 불일치로 직접 미사용.*
- **🔌 교체 가능한 에셋 팩토리**: `createCustomer(archetype)`·`createStation(type)`·`createProp(name)` 가 메시 생성을 격리. `logic.js`는 메시와 분리 → **추후 직접 만든 glTF 3D 에셋으로 통째 교체 가능**. v1은 절차적, 이음매만.
- **라이트 절차적 애니**: idle bob·걷기·집기·먹기. 본격 리깅 + KayKit 휴머노이드 애니는 추후 커스텀 에셋 단계.
- **손님 구분**: 공통 베이스 바디 + 색/소품(군모·한복·교복·가방).

## 4. 멀티플레이 & 확장성 (v1 솔로, co-op 추후)

**v1은 솔로 단독.** 온라인 co-op은 게임을 실제로 해본 뒤 가치를 판단해 추후 진행. v1에 네트워크 코드는 **0**(YAGNI), 단 이음매만 심는다:
- **`logic.js`를 순수 시뮬레이션(입력→상태)으로 격리** + **입력 소스·렌더를 어댑터화** → 추후 **호스트 권위(authoritative host) 네트워크 레이어**를 얹기만 하면 co-op 전환. (호스트=시뮬레이션 권위, 게스트=입력 전송+스냅샷 보간 렌더)
- 이 분리는 어차피 Mini-Games 패턴이라 추가 비용 거의 0.
- co-op 채택 시 추가될 것(추후): 주방 평면 2인 수용폭·스테이션 동시 점유 규칙·팀 공유 점수/콤보/라이프·룸 코드 매칭·연결 끊김 처리·네트워크 백엔드 선택(실시간 서비스 vs WebRTC P2P vs 자체 WS).

## 5. 고증 디제스트 (deep-research 검증 결과)

> 출처: 국립민속박물관 웹진(준1차)·위키백과·대전일보·서울경제·중도일보·경향신문·나무위키. 25개 클레임 → 13 확정 / 12 기각.

### ✅ 확정 (게임 척추)
| 고증 사실 | 게임 적용 | 신뢰도 |
|---|---|---|
| 음식 = 일본 우동의 현지화: 가쓰오부시→**멸치 다시 육수**, **미리 삶아둔 가락면**을 빠르게 데침 | 조리 = 데치기→육수→고명. '가락국수' 정체성 | high |
| 명성의 기원 = 호남선 분기: 서울발 호남행이 대전역에서 **기관차 방향 전환** 필요, 그 틈에 서서 먹음 | **1웨이브 = 열차 1대**. 진입=손님 입장, 전환 완료=출발 카운트다운 | high |
| 정차: 증기 **20~30분** → 디젤 **5분+** → KTX 2분 미만 | **시대 = 난이도 곡선** | high |
| **서서** 먹는 무좌석 고회전, 얼굴 파묻고 흡입 | 서서 셀프 고회전, 손님 머리 위 **초조 게이지** | high |
| 카운터 앞 **고춧가루 셀프 양념통**, 변형 주문 | 양념통 인터랙션 + **스페셜 리퀘스트** | medium |
| **'대전발 0시 50분' 막차** 실재(서울 20:45→대전 0:40→10분 교대→0:50 목포행) | **W5 막차 클라이맥스**. '대전 부르스'는 무드만(저작권 유의) | high |

### ⚠️ 공백 / 주의
- **표준 고명 미확정** ❗ — 구체 조합 주장은 검증 전부 탈락. **확정된 건 '멸치육수 + 미리 삶은 면 + 셀프 고춧가루'뿐.** → v1은 고명 1~2종 최소화 '재구성', **게임 내 '고증 노트'로 사실/재구성 구분 표기**.
- **음성/텍스처 미검증** — 안내방송·발차 신호·사투리·그릇·가격 → 시대풍 *재구성*(§7 추가 리서치로 정확도↑ 가능).
- **시대 표현** — 무대는 **1970~80년대 전성기**. 위키 '현재형'(매점 철거 등)은 outdated → 과거형으로.

## 7. 🔊 음성 자산 플랜 (voice-studio — **구현 맨 마지막**)

> ⚠️ 음성은 voice-studio에서 **별도 진행 중**. 설계·구현 흐름에서 **가장 마지막**에 통합한다(다화자 보이스 준비 상황에 맞춰).

GPT-SoVITS는 다화자·음성복제 가능 → 다양한 목소리·말투·사투리. 전부 미리 합성 `.wav` → `public/garak-guksu/audio/`.
- **손님 주문(다화자)**: 군인 / 할머니(사투리) / 통학생 / 연인 / 회사원 — "가락국수 한 그릇요!", "빨리 좀요!", "곱빼기로!"
- **주인장 추임새**: "예~ 가락국수 둘!", "뜨거우니께 후 불어 드셔!"
- **역 안내방송(PA)**: 시대풍 재구성, 에코/대역 필터.
- **발차 신호 SFX**: 호루라기·역 종·기적·칙칙폭폭.
- **상황 대사**: 만족/이탈/콤보 칭찬 + **코미디 대사**(§3.5).

**현 보이스 한계**(레제·마키마 2종) → 해결책 택1(맨 마지막 결정): 말투·속도·피치 변주 / 일부 손님만 음성 / **신규 보이스 학습**(voice-studio 진행분). 사투리·방송 문구는 §5 공백 추가 리서치(deep-research)로 정확도↑.

## 8. 기술 통합 계약 (Mini-Games 패턴, 코드 확인됨)

새 게임 추가 = 아래. (참고: `public/ppopgi/`, `public/makima-says/`)
1. **`public/garak-guksu/index.html`** — 자체완결형. `<canvas>` + importmap(`three@0.184.0`[+`cannon-es` 필요시]) + DOM HUD/시작/결과 + `<script type="module" src="./src/main.js">`. 모바일 터치·`env(safe-area)`·a11y·`prefers-reduced-motion`.
2. **`public/garak-guksu/src/*.js`** — ESM. **`logic.js` 순수 함수 분리**(Vitest, + co-op 확장 핵심). `main.js`(부트/루프)·`scene.js`·`models.js`(에셋 팩토리)·`audio.js`·`sfx.js` 등.
3. **`public/garak-guksu/audio/*.wav`** — voice-studio 산출(맨 마지막).
4. **`app/garak-guksu/page.tsx`** — ~35줄 얇은 래퍼: `"use client"` + 홈 `Link` + `LoadingOverlay` + `<iframe src="/garak-guksu/index.html">`.
5. **`app/page.tsx`** — 허브 카드 1개 추가.
6. **테스트**: `logic.js` → Vitest, 라우트 마운트 → Playwright E2E.

**음성 재생 패턴**(`makima-says/src/audio.js`): `VOICE_FILES` 맵 → `new Audio('/garak-guksu/audio/<name>.wav')` preload → `playVoice()` + WebAudio 절차적 SFX + localStorage 음소거.
