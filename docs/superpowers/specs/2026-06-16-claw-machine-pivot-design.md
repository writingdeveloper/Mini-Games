**Date:** 2026-06-16

## 1. 개념 / 동기

플레이어가 가장 좋아한 부분은 **손**이다. 쌓기에선 손이 *수단*이지만, **뽑기에선 손을 조종하는 것 자체가 게임**이다 — 그리고 느슨한 물리(쌓기의 약점)가 뽑기에선 *재미의 원천*("잡았다… 미끄러진다!")이 된다. 실력형 물리 뽑기로 피벗한다.

핵심 확장: 단일 게임이 아니라 **콘텐츠 교체형 "뽑기 머신 플랫폼"** 으로 짓는다. 엔진 하나 위에 테마별 **상품 세트(버전)** 를 갈아끼워, 3D 에셋이 확보되는 대로 버전을 계속 추가한다(감자튀김 → 인형 → …).

## 2. 아키텍처 — 엔진 + 상품 세트(버전)

- **`ClawEngine`(콘텐츠 무관):** 손 리그 + 카메라 + 입력 + **상품 더미(물리)** + **잡기-버티기 물리** + 서빙 트레이 + 라운드/점수/콤보. 어떤 상품인지 모른다.
- **`PrizeSet`(버전 = 데이터):** `{ id, name, theme(색/배경), spawn(count), items: [{ makeMesh(rng), makeBody(mat), value, weight }] }`. 엔진이 소비한다. **버전 추가 = PrizeSet 모듈 하나 추가.**
- **머신 선택:** 시작 화면에서 플레이할 머신(버전)을 고른다. 머신 추가 = 선택지 한 줄.
- **단위 경계:** 엔진은 PrizeSet 인터페이스만 의존(상품 내부 모름) → 독립 테스트·교체 가능.

## 3. 잡기-버티기 물리 (심장)

- 손을 더미 위 위치(X/Z) → 내려 **쥐기**(grip) → 가장 가까운 상품(들)을 **cannon 제약**으로 손에 부착 → **들어 옮겨** → 트레이 위에서 **놓기**(제약 해제) → 트레이에 안착 시 **득점**.
- **버티는 힘 한계:** 운반 중 상품에 걸리는 스트레스(흔들림·충돌·무게)가 임계 초과면 **제약 파손 → 슬립**(상품이 더미로 떨어짐, 0점). 부드럽고 균형 잡힌 운반 = 성공. **이미 만든 모멘텀이 "부드러움" 실력으로 직결.**
- 한 번에 여러 개 = 고가치지만 무겁고 슬립 쉬움(리스크/리워드).
- 물리 충돌은 단순 형상(박스/구) 유지(시각/물리 분리 — 기존 패턴).

## 4. 목표 / 점수 (머신별 — "가치 런")

- 제한시간(~60–90s) 내 트레이에 **담은 누적 가치** 최대화.
- 상품 종류별 가치(흔함 저점 / 희귀 고점). 연속 성공 **콤보**(기존 combo 로직 재사용). 슬립/낙하는 콤보 리셋.
- 기존 `logic/round`·`scoring`·`combo` **구조 재사용**(점수 입력만 "높이"→"담은 가치"로).

## 5. 버전 (상품 세트)

- **V1 — 감자튀김 (지금):** 기존 `fryMesh` 변형 재사용. 아이템: 일반 감자튀김(흔함·1) · 황금 감자튀김(중간·3) · 통가 간식(희귀·예: 너겟/버거, 절차적, 고점). 절차적 → 에셋 불필요.
- **V2 — 절차적 2번째 세트 (다버전 입증, 지금):** 절차적으로 만들 수 있는 테마(예: 사탕/젤리 — 둥근 RoundedBox + 밝은 정점색, 또는 간식 모둠). 목적: "PrizeSet 교체로 새 머신이 즉시 생긴다"를 실증.
- **V3+ — 에셋 의존 (추후):** 인형/플러시 등 glTF가 확보되면 같은 PrizeSet 인터페이스로 슬롯인. (이 환경엔 에셋 파이프라인 없음 → 사용자/추후.)

## 6. 재사용 매핑

- **그대로:** HandRig(IK 손)·CameraRig·Input(X/Z/**grip**/카메라)·toon 머티리얼/외곽선·AudioManager(쥐기/놓기 사운드 적합)·physics world 패턴·round/scoring/combo·(추후)MP 인프라.
- **신규:** ClawEngine(상품 더미 + 잡기 제약 + 슬립 + 트레이) · PrizeSet 인터페이스 + V1/V2 · 머신 선택 UI.
- **버림(쌓기 전용):** 높이 점수·B3 흔들림·교차 전략·타워 프레이밍.

## 7. MP (추후 — Phase 2 of pivot)

각자 더미, 베스트오브로 **담은 가치** 경쟁(높이 대신 가치 릴레이). 사보타지(더미 흔들기/그립 약화) 회귀 가능. 솔로 먼저.

## 8. 범위 / 전달

- 기존 fry 게임을 **피벗**(로직 교체, 기술 재사용). **`claw-machine-pivot` 브랜치**에서만 작업.
- **개발 순서:** ① **손맛 프로토**(손 + 더미 + 잡기-버티기-트레이 최소 스파이크)로 *그랩 필*을 먼저 검증 → ② 엔진 + V1(+V2) + 머신 선택 정식 통합 → ③ 제 QA(게이트+리뷰+플레이 검증) → ④ **사용자 QA**(직접 플레이하실 빌드 전달).
- **프로덕션 자동배포 ❌.** 라이브 쌓기 게임은 사용자 승인 전까지 유지.

## 9. 테스트

- **Unit(Vitest):** 순수 로직 — 가치 점수 집계, 콤보(재사용), 슬립 판정 임계(순수 함수로 분리), PrizeSet 가중 샘플링.
- **e2e(Playwright):** 캔버스 0 에러 · 머신 선택→플레이 · 잡기→운반→트레이 안착으로 점수 증가 · 라운드 종료. 프로토는 별도 verify 스크립트.
- Lint/type 그린.

## 10. 미해결 / 후속

- 슬립 임계·그립 반경·제약 강성 튜닝(프로토에서 손맛으로).
- V2 절차적 테마 확정(구현 중 절차적 실현성으로 결정).
- 머신 선택 UI 형태(시작 화면 카드 vs 게임 내 셀렉터).
- MP 피벗(가치 릴레이) 별도.
- 게임 이름(탑 아님) 재명명.
- 에셋 기반 버전(인형 등)은 glTF 확보 시.
