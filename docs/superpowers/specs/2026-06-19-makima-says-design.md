# 마키마 says (복종 게임) — 설계 문서

작성일: 2026-06-19
라우트: `/makima-says` · 제목: **마키마 says**

## 한 줄 요약
지배 악마 **마키마**와 폭탄 악마 **레제**가 번갈아 방향 명령을 외친다. 마키마에겐
복종하고(외친 방향 입력), 레제의 유혹은 거부한다(아무것도 누르지 않기). 정통
"사이먼 says"에 체인소맨 두 보이스를 입힌 싱글플레이 반응 게임.

## 핵심 루프
1. 한 라운드마다 **마키마 또는 레제**가 방향(⬆️⬇️⬅️➡️) 하나를 음성 + 화면으로 명령.
2. 판정 (제한 시간 = 라운드별 반응 창):
   - **마키마 명령** → 외친 방향을 시간 내 정확히 입력해야 성공. 미입력/오입력 = 실패.
   - **레제 명령** → 반응 창 동안 **아무 입력도 하지 않아야** 성공. 입력하면 = 유혹에 넘어감 = 실패.
3. 성공 → 콤보 +1, 점수 += 기본점 × 콤보 배수. 실패 → 라이프 −1, 콤보 리셋, 폭발 연출.
4. 라이프 3개 소진 시 게임 오버 → 결과(점수·최고 콤보·라운드) + 리플레이.

### 난이도 곡선
- 반응 창은 시작 `1.4s`에서 라운드마다 감소, 하한 `0.55s`.
- 레제 등장 확률은 초반 25% → 후반 45%로 증가.
- 페이크 연출(레제가 마키마처럼 차분하게, 또는 두 패널이 동시에 번쩍) — 폴리시 단계.

## 화면 구성
- 좌측 패널 = **마키마**(차분·지배 톤), 우측 패널 = **레제**(도발·유혹 톤). 말하는 쪽이 빛남.
- 중앙 = 큰 방향 타깃 글리프 + 카운트다운 링.
- HUD = 콤보(배수) · 점수 · 라이프(💣 ×3) · 최고 콤보.
- 피드백: 성공 = 초록 펄스 + 정답음, 실패 = 붉은 화면 플래시 + 폭발음 + 패널 흔들림.
- 자막(aria-live): "마키마: 왼쪽" / "레제: 위… (거부!)" 형태로 누가·무엇을 말했는지 텍스트로도 표기.

## 판정 규칙 (순수 함수로 분리, 단위 테스트 대상)
- `judge(command, input)`:
  - `command.speaker === 'makima'`: `input === command.dir` → hit, else miss.
  - `command.speaker === 'reze'`: `input === null`(반응 창 내 무입력) → hit, 어떤 입력이든 → miss(폭발).
- `comboMult(streak)`, `reactionWindow(round)`, `rezeChance(round)` — 모두 순수 함수.

## 보이스 (MCP voice-studio로 사전 합성)
런타임에 MCP를 쓰지 않는다. 빌드 전 WAV를 미리 합성해 `public/makima-says/audio/`에
저장하고 게임은 정적 오디오만 재생(ppopgi의 `reze.mp3`와 동일 방식).

- 보이스: 마키마 한국어는 **`마키마-v2`**, 레제는 **`레제`**.
- 각 보이스: 방향 4종(왼쪽/오른쪽/위/아래) + 인트로 1 + 성공 도발 1 + 실패 도발 1 ≈ 7클립.
  - 마키마: 명령조·지배적. 레제: 간드러지고 장난스럽게.
- 총 ~14클립. 정답음·폭발음 등 SFX는 WebAudio로 합성(추가 클립 불필요).
- 파일명 규칙: `makima-left.wav`, `reze-up.wav`, `makima-intro.wav` 등.

## 기술 구성
- Next.js 클라이언트 라우트 `/makima-says` (`app/makima-says/page.tsx`).
  로직은 프레임워크 비의존 모듈로 분리해 단위 테스트 가능하게.
  - `lib/engine.ts` 류: 라운드 생성·판정·콤보·난이도(순수 함수).
  - `lib/audio.ts` 류: 클립 프리로드·재생·뮤트.
  - `MakimaSays.tsx`: 상태·렌더·입력 바인딩(키보드 ←↑↓→, 모바일 방향 버튼/스와이프).
- 허브(`app/page.tsx`)에 카드 추가.
- 접근성: 키보드 완전 조작, aria-live 자막, 뮤트 토글(영구저장), `prefers-reduced-motion`,
  방향 버튼에 role/aria-label. ppopgi 수준 준수.
- 디버그 훅 `window.__makima` (현재 명령/판정/콤보/라이프/시드) — e2e·QA용.

## 테스트
- 단위: `judge`, `comboMult`, `reactionWindow`, `rezeChance`, 라운드 시퀀스 결정성(시드).
- e2e(Playwright): 시작 → 명령 표시 → 정답 입력 → 콤보 증가 1사이클, 레제 명령 거부 1사이클.
  (`--workers=2`로 실행 — 메모리상 8워커 플레이크 주의.)

## 범위 밖 (YAGNI)
- 멀티플레이어 · 리더보드 · 결제 연출 · 동작(앉아/손) 입력 · 보이스 런타임 합성.

## 마일스톤
1. 보이스 클립 사전 합성(MCP) + 정적 저장.

3. UI 컴포넌트 + 오디오 + 입력 + 접근성.
